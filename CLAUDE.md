# Project: dictee
Used to test spelling, math, Arduino and topography capabilities of members of DJO, a Dutch 'hackerspace' for youth aged 11-18.

## Tech stack
- Bun as JavaScript runtime
- Hono as web server framework
- Socket.IO for real-time updating on web pages

## Important rules
- The web server should run on **port 7777**. Do not change it and if you notice that someone else changed it, change it back to 7777.
- Never commit changes by yourself, but ask the end user to do so.
- The codebase should be written in English, but the website's actual content must be in Dutch.
- Files in `/data` do not contain any code. Do not modify them unless the end user explicitly asks so!
- Stick to the colors and gradients that already exist in the CSS files.

## A useful command
`bun start`: start the web server
